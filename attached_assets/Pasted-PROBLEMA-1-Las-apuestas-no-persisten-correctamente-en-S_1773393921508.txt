EL PROBLEMA
El schema Drizzle en shared/schema.ts está completamente desalineado con la tabla real:

Drizzle define id como integer().generatedAlwaysAsIdentity() pero la tabla usa uuid.
Drizzle define league: text("league") pero la tabla usa competition.
Drizzle define date como text pero la tabla usa timestamptz.
El tipo Bet (inferido de Drizzle) tiene id: number pero debería ser id: string (uuid).
profit siempre se guarda como 0 — nunca se calcula.
La app actualmente funciona parcialmente porque dashboard.tsx usa betService.ts (cliente Supabase directo) para las bets, NO las rutas del servidor. Pero hay desajustes en el mapeo que causan pérdida de datos.
